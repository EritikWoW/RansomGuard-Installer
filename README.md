# RansomGuard — official Windows installer

This repository is the **public, binary-only distribution channel** for RansomGuard. The application source code and internal qualification records are kept in a separate private repository.

## Download

**No production installer is published yet.** When the first production-signed release has passed validation, download it from [GitHub Releases](https://github.com/EritikWoW/RansomGuard-Installer/releases). Each release contains only one Windows x64 executable named `RansomGuard-Installer-<version>.exe`.

Do not download RansomGuard installers from third-party mirrors. GitHub's autogenerated source ZIP/TAR files contain this distribution repository's metadata only; **they are not installers**.

## Automatic updates

An installed RansomGuard client with an embedded stable-channel trust root checks the signed update manifest after startup and periodically thereafter. A newer verified installer is downloaded into a local cache; users can then approve installation from inside RansomGuard. Update installation requires administrative authorization on currently released clients.

The production update manifest is published to [stable/update-manifest.json](https://raw.githubusercontent.com/EritikWoW/RansomGuard-Installer/main/stable/update-manifest.json) **only after a qualified signed installer has actually been released**. Its absence means no stable release is available, not that unsigned or test builds should be installed.

RansomGuard checks the update metadata's ECDSA signature and each downloaded installer's exact size, SHA-256 and Windows Authenticode signature before installation. The signing private key and application source code are never published here.

## Versioning

Release names use `vMAJOR.MINOR.PATCH`; corresponding Windows binaries use `MAJOR.MINOR.PATCH.0`. Development and laboratory builds are not published as stable releases.

## Support and security

Do not upload private data, executable samples or incident evidence to this public repository. This repository is for installer distribution only.
